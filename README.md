# Sweet Haven Cake & Bakery

A responsive bakery landing page inspired by the supplied reference design.

## Run
Open `index.html` in a browser. For best video behavior, run it with a small local server (for example VS Code Live Server).

## Structure
- `index.html` — page structure
- `css/style.css` — custom styling + responsive media queries
- `js/app.js` — mobile navigation, search modal, cart counter, FAQ, form feedback and back-to-top
- `assets/images/` — image assets/poster/reference
- `assets/video/hero-video.mp4` — supplied hero video
- `assets/icons/` — local SVG icons
- `assets/google-fonts/` — Google font setup

## Reference assets
Product, offer, customer and map visuals are cropped from the supplied design reference and stored locally in `assets/images/`.
